# ASHA Saheli 🩺

Voice clinical assistant for rural health workers (ASHA workers).

**Live demo:** https://asha-saheli-voice-clinical-assistant-for-rural-he.ai.studio

## What it does
- Offline-first Hindi voice logging
- Flags high-risk cases
- Shows due lists for visits
- Auto-generates RCH paperwork

## How to run it
1. `npm install`
2. Create a `.env` file and add your Gemini API key
3. `npm run dev`
